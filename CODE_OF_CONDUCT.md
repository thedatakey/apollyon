# Code of conduct

Apollyon contributors are expected to be respectful, inclusive, professional,
and focused on improving defensive software. Harassment, personal attacks,
discrimination, threats, doxxing, and publishing another party’s secrets or
private vulnerability details are not acceptable.

Assume good faith while challenging technical claims with evidence. Security
disagreements should focus on reproducibility, threat models, assumptions, and
impact—not status or personality. Maintainers may edit or remove contributions
and participation that violate these expectations.

To report conduct concerns, use a private maintainer channel. Until one is
published, request private contact through a non-sensitive GitHub issue.
